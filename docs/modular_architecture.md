# TIDE Analysis Pipeline - Modular Architecture

## Overview

The CRISPR TIDE Analysis Pipeline has been refactored into a clean, modular architecture for better maintainability and extensibility.

## Architecture Diagram

```
run_analysis.py (Entry Point)
    └── src/tide_batch_analysis.py (Main Orchestrator)
         ├── utils/ab1_parser.py      (AB1 file parsing)
         ├── utils/sequence_analysis.py (Sequence operations)
         ├── utils/tide_algorithm.py   (TIDE decomposition)
         ├── utils/primer_design.py    (Primer design)
         ├── utils/visualization.py    (Plotting & graphics)
         ├── utils/file_management.py  (File operations)
         └── utils/ab1_analyzer.py     (Detailed AB1 analysis)
```

## Command Line Options

The pipeline now supports various command-line arguments for flexible control:

### Basic Usage
```bash
# Run with default settings (70% similarity threshold)
python run_analysis.py

# Or run the main module directly
python src/tide_batch_analysis.py
```

### Available Options

#### `--force-plot`
Generate plots even when validation fails. The plots will include warning messages.
```bash
python run_analysis.py --force-plot
```

#### `--similarity-threshold <value>`
Set custom similarity threshold (default: 70%)
```bash
python run_analysis.py --similarity-threshold 50
```

#### `--skip-validation`
Skip all validation checks (not recommended)
```bash
python run_analysis.py --skip-validation
```

#### `--interactive`
Ask for confirmation before processing each gene
```bash
python run_analysis.py --interactive
```

#### `--no-archive`
Do not archive previous output files
```bash
python run_analysis.py --no-archive
```

#### `--genes <gene1> <gene2> ...`
Process specific genes only
```bash
python run_analysis.py --genes vmat1 ddc
```

## Validation Logic

The pipeline validates sequences before plotting based on:

1. **Sequence Similarity**: Control and edited sequences must have >70% similarity (configurable)
2. **Cut Site Bounds**: Expected cut site must be within sequence length
3. **gRNA Presence**: gRNA must be found in the mRNA reference

### Validation Outcomes

- **No Issues**: Normal TIDE analysis plot generated
- **Warnings (similarity 50-70%)**: Plot generated with yellow warning box if `--force-plot` used
- **Errors (similarity <50% or cut site out of bounds)**: 
  - Error plot generated by default
  - Analysis plot with red warning box if `--force-plot` used

## Output Files

Each gene folder will have:

```
gene_folder/
├── archive/                    # Previous run outputs
│   └── run_YYYYMMDD_HHMMSS/  # Timestamped folders
├── output/                     # Current run outputs
│   ├── ab1_analysis_gene.txt
│   ├── recommendations_gene_timestamp.txt
│   └── tide_analysis_gene_timestamp.png (or _WARNING.png/_ERROR.png)
```

### File Types

1. **ab1_analysis_gene.txt**: Detailed AB1 file analysis including:
   - Sequence lengths and quality scores
   - Sequence comparison
   - gRNA presence in AB1 sequences
   - mRNA reference analysis

2. **recommendations_gene_timestamp.txt**: Structured report with:
   - gRNA summary with positions
   - TIDE analysis results
   - Primer recommendations
   - PCR conditions

3. **tide_analysis_gene_timestamp.png**: 4-panel plot showing:
   - Chromatogram overlay
   - Sequence alignment
   - Indel spectrum or signal analysis
   - Editing efficiency pie chart

## Module Descriptions

### `utils/ab1_parser.py`
- `parse_ab1()`: Extract sequence and chromatogram traces
- `get_quality_scores()`: Get Phred quality scores

### `utils/sequence_analysis.py`
- `align_sequences()`: Global sequence alignment
- `calculate_similarity()`: Calculate sequence similarity percentage
- `find_divergence_point()`: Find where sequences diverge
- `find_grna_in_sequence()`: Locate gRNA in sequences

### `utils/tide_algorithm.py`
- `decompose_traces_tide()`: TIDE decomposition algorithm
- `calculate_editing_efficiency_fallback()`: Fallback efficiency calculation

### `utils/file_management.py`
- `archive_output_files()`: Move old outputs to archive
- `ensure_output_dir()`: Create output directory
- `save_results()`: Save analysis results
- `check_required_files()`: Validate required input files

### `utils/primer_design.py`
- `design_primers_with_primer3()`: Professional primer design
- `design_simple_primers()`: Fallback primer design
- `generate_primer_recommendations()`: Format primer recommendations

### `utils/visualization.py`
- `validate_for_plotting()`: Check if plotting should proceed
- `plot_tide_analysis()`: Create main analysis plot
- `plot_error_figure()`: Create error visualization
- Various subplot functions for different visualizations

### `utils/ab1_analyzer.py`
- `analyze_ab1_details()`: Comprehensive AB1 file analysis

## Best Practices

1. **Default Usage**: Run without arguments for standard analysis
2. **Validation Issues**: Use `--force-plot` to see plots with warnings
3. **Debugging**: Check `ab1_analysis_*.txt` files for sequence details
4. **Archiving**: Let the pipeline archive old files to track analysis history
5. **Batch Processing**: Process all genes at once for efficiency

## Troubleshooting

- **Import Errors**: Ensure you're running from the project root with the virtual environment activated
- **Missing Files**: Check that all required files (control.ab1, edited.ab1, grna.txt, mrna.txt) exist
- **Low Similarity**: Your sequences might be from different regions - check primer design
- **Cut Site Out of Bounds**: Sequence doesn't cover the gRNA target region - need longer sequencing reads
